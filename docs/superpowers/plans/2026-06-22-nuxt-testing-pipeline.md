# Nuxt Testing Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configure the project test workflow according to the Nuxt 4 testing guide and add a GitHub Actions CI workflow.

**Architecture:** Keep fast server tests in a Node Vitest project and add a separate Nuxt runtime Vitest project for tests that require a Nuxt app context. CI runs the same local quality gates: lint, typecheck, tests, and build.

**Tech Stack:** Nuxt 4, Vitest 4, `@nuxt/test-utils`, `@vue/test-utils`, `happy-dom`, pnpm 11, GitHub Actions.

## Global Constraints

- Preserve existing tests under `tests/server/**`.
- Use Vitest projects rather than one global Nuxt test environment.
- Keep `pnpm test` and `pnpm test:run`.
- Add `pnpm test:unit` and `pnpm test:nuxt`.
- CI must use `pnpm install --frozen-lockfile`.
- CI must run `pnpm lint`, `pnpm typecheck`, `pnpm test:run`, and `pnpm build`.

---

## File Structure

- Modify `package.json`: add Nuxt testing dependencies and targeted test scripts.
- Modify `pnpm-lock.yaml`: lock the added dev dependencies.
- Modify `vitest.config.ts`: define `unit` and `nuxt` Vitest projects.
- Modify `nuxt.config.ts`: add `@nuxt/test-utils/module`.
- Create `.nuxtrc`: record the Nuxt module setup metadata generated by `nuxt prepare`.
- Create `tests/nuxt/runtime.test.ts`: smoke test that proves the Nuxt runtime test project starts.
- Create `.github/workflows/ci.yml`: GitHub Actions workflow.

- [ ] **Step 2: Update scripts**

Set `package.json` scripts to include these entries:

```json

  "test": "vitest",
  "test:run": "vitest run",
  "test:unit": "vitest --project unit",
  "test:nuxt": "vitest --project nuxt"
}
```

- [ ] **Step 3: Update Vitest config**

Replace `vitest.config.ts` with:

```ts
import { fileURLToPath } from 'node:url'
import { defineVitestProject } from '@nuxt/test-utils/config'
import { defineConfig } from 'vitest/config'

const rootDir = fileURLToPath(new URL('.', import.meta.url))
const appDir = fileURLToPath(new URL('./app', import.meta.url))

const aliases = {
  '~~': rootDir,
  '@@': rootDir,
  '~': appDir,
  '@': appDir
}

export default defineConfig({
  test: {
    projects: [
      {
        resolve: {
          alias: aliases
        },
        test: {
          name: 'unit',
          environment: 'node',
          globals: false,
          include: ['tests/server/**/*.{test,spec}.ts']
        }
      },
      await defineVitestProject({
        test: {
          name: 'nuxt',
          environment: 'nuxt',
          globals: false,
          include: ['tests/nuxt/**/*.{test,spec}.ts'],
          environmentOptions: {
            nuxt: {
              domEnvironment: 'happy-dom'
            }
          }
        }
      })
    ]
  }
})
```

- [ ] **Step 4: Run the Nuxt project**

Run: `pnpm vitest run --project nuxt`

Expected: PASS for `tests/nuxt/runtime.test.ts`.

- [ ] **Step 5: Run all tests**

Run: `pnpm test:run`

Expected: PASS for both `unit` and `nuxt` projects.

### Task 4: Add GitHub Actions CI

**Files:**
- Create: `.github/workflows/ci.yml`

**Interfaces:**
- Consumes: pnpm scripts from `package.json`.
- Produces: CI workflow named `CI`.

- [ ] **Step 1: Create workflow**

```yaml
name: CI

on:
  push:
    branches:
      - main
  pull_request:

permissions:
  contents: read

jobs:
  verify:
    name: Verify
    runs-on: ubuntu-latest

    steps:
      - name: Checkout
        uses: actions/checkout@v5

      - name: Setup pnpm
        uses: pnpm/action-setup@v4

      - name: Setup Node.js
        uses: actions/setup-node@v5
        with:
          node-version: 24
          cache: pnpm

      - name: Install dependencies
        run: pnpm install --frozen-lockfile

      - name: Lint
        run: pnpm lint

      - name: Typecheck
        run: pnpm typecheck

      - name: Test
        run: pnpm test:run

      - name: Build
        run: pnpm build
```

- [ ] **Step 2: Verify workflow syntax by local inspection**

Run: `Get-Content -Raw .github/workflows/ci.yml`

Expected: The workflow contains checkout, pnpm setup, Node 24 setup, frozen install, lint, typecheck, test, and build steps.
