# 每日 60 秒公共接口

`GET /v1/60s` 获取“每天 60 秒读懂世界”的新闻摘要和每日微语，数据来源为 [vikiboss/60s-static-host](https://github.com/vikiboss/60s-static-host) 的公开静态数据。

## 请求参数

| 参数 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `date` | 否 | 上海时区的当天 | 严格的 `YYYY-MM-DD` 日期；未指定时若当天尚未更新，最多向前回退两天 |
| `encode` / `encoding` | 否 | `json` | `json`、`text`、`markdown`、`md` |

```bash
# 获取最新一期
curl 'http://127.0.0.1:3000/v1/60s'

# 获取指定日期
curl 'http://127.0.0.1:3000/v1/60s?date=2026-08-07'

# Markdown 输出
curl 'http://127.0.0.1:3000/v1/60s?encode=markdown'
```

## 缓存与错误

服务端按实际内容日期共享缓存 30 分钟，成功响应允许客户端缓存 15 分钟。

- 日期格式错误或日期不存在：`400 INVALID_DATE`。
- 指定日期没有内容，或上游请求、JSON 与数据结构异常：`502 UPSTREAM_ERROR`。
